# IWBF Terminology and UI Language

The app UI must be in English.

Use IWBF-style terms where practical. This document is a terminology guide, not a replacement for official IWBF documents.

## Core Terms

- Competition
- Game
- Team
- Player
- Classifier
- Chief Classifier
- Classification Panel
- Player Evaluation
- Sport Class
- Sport Class Status
- Observation in Training
- Observation in Competition
- Observation Assessment
- First Appearance
- Minimum Impairment Criteria (MIC)
- Eligible Impairment
- Health Condition
- Impairment
- Tracking Code
- Final Decision

## Sport Classes

- 1.0
- 1.5
- 2.0
- 2.5
- 3.0
- 3.5
- 4.0
- 4.5
- NE

## Sport Class Status Values

Use these values:

- N - New
- C - Confirmed
- R - Review
- FRD - Review with Fixed Review Date
- CNC - Classification Not Complete
- OA - Observation Assessment
- RT - Sport Review (Transition), if needed
- CT - Confirmed Transition, if needed

## App-Specific Status Values

These are workflow labels, not official IWBF statuses:

- Not Observed
- Quick Check
- Observe
- Discuss
- Finalized

## Wording Preference

Prefer short, operational labels.

Good:

- `Starting`
- `My Opinion`
- `Final`
- `Flag Moment`
- `Link Current Video`

Avoid verbose labels during game flow.
